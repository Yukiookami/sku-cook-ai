# S01 菜谱一览设计书

状态：Web画面已实现；A02/A03/A14 API client已按shared Contract接入并校验响应。尚未在可用服务/数据库环境执行真实HTTP业务验收。路由 `/recipes`，组件 `RecipeListView.vue`。产品主入口；无独立管理首页。

## 1. 信息结构

```text
吃什么饭                  新增  更多
今天吃什么？  随机推荐
推荐区（点选后）：青椒肉丝 · 查看做法 · 换一个
搜索菜名
全部  家常菜  快手  汤             选菜
番茄炒蛋
家常菜 · 快手 · 15 分钟
十分钟家常菜
------------------------------------
青椒肉丝 ...
加载中 / 已经到底了 / 点击重试
```

“更多”包含“批量导入”“查看厨房菜单”“打开厨房显示”（`/kitchen`，让闲置平板可进入 S06）和“做饭历史”（[S08](S08_COOKING_HISTORY.md)），不新增设置、个人中心或收藏。tag 选择器超宽时使用换行 / 折叠展开，厨房屏之外允许正常滚动。内容宽度手机适配，≥768px 可两列，但选菜栏和列表顺序稳定，桌面不另做管理端。

标题下方保留轻量“今天吃什么？随机推荐”入口与就地结果区，结果使用文字菜名、标签、时长/简介，不另建推荐页面或增加食品图片。该区明确“从全部菜谱随机”，与下方列表搜索/标签分离。

## 2. 交互与数据

- [A02](../apis/A02_RECIPES_GET.md)：首次和触底每次 20 条，更新倒序；搜索仅菜名、单 tag 筛选，可组合。搜索输入防抖建议 300ms，Enter 立即搜索。
- [A03](../apis/A03_RECIPE_TAGS_GET.md)：所有现有 tag，而非当前页标签。标签读取失败单独重试，不把“无标签”和失败混淆，不阻止查看列表。
- 查询条件用 URL query 保留；改变条件清空结果、重置 page=1，取消或忽略旧请求，禁止串入旧筛选结果。加载中不重复发同页；失败保留已有项，底部显示重试。
- 进入详情可返回原滚动位置；新增 / 编辑 / 删除 / 导入导致数据变化后重新读第一页，避免旧分页和新排序拼接出现重复漏项。
- 点击“选菜”进入多选，亦可长按条目；不能只有长按入口。选中项最多 10 道，顺序按勾选先后；不同已加载页之间保留选择。取消多选清空选择。
- 多选期间点条目只切换勾选，不进详情；底部显示“已选 N 道”“发送到厨房（N）”，N=0 时禁用。超过 10 道明确提示，不能静默截断。
- 打开 [S07](S07_KITCHEN_PANEL.md) 发送弹层，发送成功退出多选；失败保留。筛选切换可保留已选项，但计数明确，弹层列出全部选择，避免隐藏选择造成误发。
- 多选发送时各菜目标份数默认RecipeSummary.servings，在S07逐道调整；列表不批量修改原菜谱份数或食材。

### 2.1 随机推荐与换一个

- 点击随机推荐才请求[A14](../apis/A14_RECIPE_RANDOM_GET.md)，不在进页时自动抽取，不后台推送；候选范围全部默认用户菜谱，忽略列表搜索、标签和已加载页。
- 有结果显示“查看做法”“换一个”；换一个带当前结果id为excludeRecipeId，成功才替换结果。只排除当前菜，允许较早结果再次出现，推荐本身不勾选列表、不改变已有多选、不写厨房。
- 查看做法跳既有S02，原份数为默认目标，后续发送仍走S07。推荐菜未在已加载列表也可直接用id进详情，不先加载所有分页。
- EMPTY_LIBRARY显示“还没有菜谱，先新增或导入再随机推荐”，提供对应入口；NO_ALTERNATIVE显示“没有其他可推荐的菜谱”，保留当前菜并禁用“换一个”直到用户重新推荐或菜谱数据变化。不能把原菜换个动画说成新结果。
- 请求中禁用随机/换一个以防连点，换菜时保留旧结果、加载文案就地显示；失败保留旧结果，明确错误和重试，重试沿用该次排除id，不把失败当空库。切路由/重新推荐时取消或忽略旧响应。
- 列表筛选改变不重抽/清掉推荐区。回列表可保留当前推荐但不当长期历史保存；用户点击“随机推荐”重新开始时可省略排除id，只有“换一个”必须排除当前。新增/编辑/删除/导入引起列表失效时同步清理推荐旧摘要及无其他菜标记，不自动抽取。
- 候选在看详情前被删除时S02按404显示；服务端当前确实EMPTY_LIBRARY时清掉过期推荐并给新增入口，不掩盖数据库故障。

## 3. 状态

首次加载在标题下显示“正在加载菜谱”状态，直到请求成功或失败；失败后才显示可重试的错误，不显示空列表。真正零菜谱显示“还没有菜谱 / 去新增 / 批量导入”。搜索无结果显示“没有找到匹配的菜谱 / 清除筛选”，不当作库为空。追加失败就地重试；最后一页显示“已经到底了”。列表按内容纵向滚动，离线保留已加载项并提示不能刷新，不提供离线写入。

## 5. 验收

20 / 21 / 40 / 41 条触底行为正确；筛选变更时旧请求不污染结果；已选跨页跨筛选显示一致；选择 10 / 11 道边界明确；恢复滚动与修改后重读不混用；无图、无不在范围内的功能。

随机区主动读取、忽略列表筛选/分页、排除当前、空库/唯一菜、失败保留/正确重试、防连点/旧响应、跳详情原份数均验证；查看/换菜不改变厨房或已有多选，手机无通知。
