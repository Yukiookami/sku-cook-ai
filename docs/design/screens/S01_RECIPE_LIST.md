# S01 菜谱一览设计书

状态：待实现。路由 `/recipes`，组件 `RecipeListView.vue`。产品主入口；无独立管理首页。

## 1. 信息结构

```text
家庭菜谱                  新增  更多
搜索菜名
全部  家常菜  快手  汤             选菜
番茄炒蛋
家常菜 · 快手 · 15 分钟
十分钟家常菜
------------------------------------
青椒肉丝 ...
加载中 / 已经到底了 / 点击重试
```

“更多”包含“批量导入”“查看厨房菜单”，不新增设置、个人中心或收藏。tag 选择器超宽时使用换行 / 折叠展开，厨房屏之外允许正常滚动。内容宽度手机适配，≥768px 可两列，但选菜栏和列表顺序稳定，桌面不另做管理端。

## 2. 交互与数据

- [A02](../apis/A02_RECIPES_GET.md)：首次和触底每次 20 条，更新倒序；搜索仅菜名、单 tag 筛选，可组合。搜索输入防抖建议 300ms，Enter 立即搜索。
- [A03](../apis/A03_RECIPE_TAGS_GET.md)：所有现有 tag，而非当前页标签。标签读取失败单独重试，不把“无标签”和失败混淆，不阻止查看列表。
- 查询条件用 URL query 保留；改变条件清空结果、重置 page=1，取消或忽略旧请求，禁止串入旧筛选结果。加载中不重复发同页；失败保留已有项，底部显示重试。
- 进入详情可返回原滚动位置；新增 / 编辑 / 删除 / 导入导致数据变化后重新读第一页，避免旧分页和新排序拼接出现重复漏项。
- 点击“选菜”进入多选，亦可长按条目；不能只有长按入口。选中项最多 10 道，顺序按勾选先后；不同已加载页之间保留选择。取消多选清空选择。
- 多选期间点条目只切换勾选，不进详情；底部显示“已选 N 道”“发送到厨房（N）”，N=0 时禁用。超过 10 道明确提示，不能静默截断。
- 打开 [S07](S07_KITCHEN_PANEL.md) 发送弹层，发送成功退出多选；失败保留。筛选切换可保留已选项，但计数明确，弹层列出全部选择，避免隐藏选择造成误发。

## 3. 状态

首次加载显示“正在加载菜谱”；真正零菜谱显示“还没有菜谱 / 去新增 / 批量导入”。搜索无结果显示“没有找到匹配的菜谱 / 清除筛选”，不当作库为空。追加失败就地重试；最后一页显示“已经到底了”。离线保留已加载项并提示不能刷新，不提供离线写入。
