# S05 JSON 批量导入设计书

状态：待实现。路由 `/recipes/import`，组件 `RecipeImportView.vue`。从列表“更多”或空库入口进入。

## 1. 信息结构

顶栏“返回 / 批量导入”；说明“仅 JSON，最多 100 道、1 MiB；同名或任意一条错误，整批不导入”。输入区分“选择 JSON 文件”和“粘贴 JSON”两个模式，切换明确替换当前输入，不把两份内容混合。

文件模式用原生文件选择，仅 .json；显示文件名、大小、移除 / 重新选择。粘贴模式为多行等宽字体文本框。提供“查看示例”展开示例文本并可复制（复制失败可手动选中），不是抓取网址或 AI 生成入口。

## 2. 状态机与 API

```text
无输入 → 待校验 → 校验中 → 校验通过 → 导入中 → 成功
                     ↘ 校验失败 → 修改后待校验
```

- 本地检查字节大小和 JSON 语法，不能替代服务端条目校验。错误保留原文。
- 导入servings省略默认1，scaleWithServings省略默认true；原2/4人份直接按原份数导入，不强制转1人份。示例说明字段含义，预校验/写入都使用同一默认规则；文字量保持原文。
- 点击“校验 JSON”调用 [A08](../apis/A08_IMPORT_VALIDATE_POST.md)，显示通过数量或第几道菜 / 字段 / 原因列表。同名、步骤编号非法等都可定位。
- 通过后显示“校验通过，共 N 道，尚未写入”，按钮变“导入 N 道菜谱”；正式调用 [A09](../apis/A09_IMPORT_POST.md)，输入必须是同一份校验过的内容。
- 修改输入、重新选文件、切模式时立即取消通过标记。执行中锁输入和按钮；新校验也忽略旧响应。
- 正式导入仍重新校验，可能因现有数据变化失败。任何失败零写入；展示报告并回待校验，不将预校验当作成功。
- 成功显示“已导入 N 道菜谱”“查看菜谱一览”“继续导入”；链接 S01、刷新第一页。不自动重复导入。
- 若提交后网络中断，显示“导入结果暂未确认，请查看菜谱一览后再决定是否重试”。不自动重发，不显示 0 条失败作为确定结果。
