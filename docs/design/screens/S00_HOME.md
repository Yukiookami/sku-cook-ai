# S00 基础首页设计书

状态：技术验证页已实现。组件 `HomeView.vue`，路由 `/health-check`；正式入口 `/` 重定向 `/recipes`，技术验证页只从更多菜单进入，不是正式产品首页。

## 1. 目的与布局

给开发者验证 Web → Axios → Vite 代理 → Fastify → shared Contract，不验证数据库。手机居中单栏，最大内容宽度 720px；小字“家庭菜谱”、标题“吃什么饭”、说明、一个“检查后端连接”按钮。浏览器标题及 PWA 安装名称也为“吃什么饭”。无图片、无登录、无菜谱假数据。

## 2. 状态与行为

| 状态   | 显示 / 行为                                                     |
| ------ | --------------------------------------------------------------- |
| 初始   | “这里检查后端存活状态，不验证数据库；菜谱业务请从菜单进入。”    |
| 请求中 | 按钮 loading、禁止重复点击                                      |
| 成功   | “连接成功：sku-cook-ai-api（不代表数据库已连接）”               |
| 失败   | “无法连接后端，请确认 API 已启动，并检查代理配置。”；可再次点击 |

使用 [A01](../apis/A01_HEALTH_GET.md)；响应按 shared schema 校验，错误写开发控制台并呈现可读提示，不展示异常原文。状态文本使用 status / alert。

## 3. 设计图提示词入口

[S00 当前主提示词与补充状态](images/PROMPTS.md#s00_home)统一维护生成/修改设计图的提示词，本设计书不重复存放。

## 4. 验收

初始、成功、失败三种文本区分明确；按钮重试正常；设计不能让用户误以为菜谱业务或数据库已经实现。
