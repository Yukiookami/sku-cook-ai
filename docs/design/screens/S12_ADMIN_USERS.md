# S12 只读管理员用户列表

状态：Web/API/shared已实现，mock行为测试覆盖；本机管理员迁移已应用，无独立设计图，不修改PNG。

## 入口与范围

路由 `/admin/users`，仅首页“更多”的超级管理员账号操作区显示“管理员页面”。直接访问仍需会话；普通用户显示权限错误且不请求列表，API独立校验权限。使用用户ID作为稳定标识，不用用户名决定管理员身份。

## 内容与交互

复用PageHeader与Memo纸卡，返回菜谱首页；说明只查看、不修改账号且邮箱未验证。
每项展示用户名、用户ID、邮箱（null显示“未设置”）及本地化注册时间。
[A26](../apis/A26_ADMIN_USERS_GET.md)固定20项分页，上一页/下一页，边界禁用，请求中禁止重复。初始加载状态可读，失败显示错误和重试、保留原列表，真实空结果显示“暂无注册用户”；卸载忽略迟到响应。无删除、修改密码、权限管理或查看他人业务数据入口。
