## 布局与版本说明

- 统一奶油白、蜂蜜黄、深棕文字、圆角便签卡、轻虚线与少量CSS几何装饰。厨房使用相同彩色风格，不再采用旧黑白方案。
- 手机首屏不强塞完整长表单；S03/S04只展示宽松基本信息区，食材控件、换算开关、步骤及其他字段通过正常滚动查看。中段图是同一表单的滚动位置，不是新增路由；编辑页复用相同表单。
- 厨房图中的页码和分页按钮是旧交互，当前改为当前一道菜的内容纵向滚动，并通过菜单或上下道按钮切换菜谱；图片仅作Memo配色、卡片与横屏分栏的视觉参考。
- 用户的Android平板约10寸；屏幕英寸不能推导CSS视口。750×1000与1000×750只是参考比例，最终按系统缩放、浏览器、文字换行和安全区真机验收。
- S08首次有PNG：按每次做饭分组，显示当时菜名/目标份数和查看最新做法入口；无统计、库存或通知功能。
- S05的JSON只显示结构片段，缺少完整食材和步骤，不能作为有效导入文件；完整示例以业务Contract为准。
- 历史入口、手动记录弹窗、完成成功/冲突、异常状态及长表单末段仍未全部画出，不能把主图存在当作覆盖所有状态。
- 生成图仅是视觉参考，可能出现字号、圆角、细微色差或装饰渲染偏差。实现时用清晰系统字体、纯色CSS和规范的点击区域；不复制生成字形或据图增加字段限制。
- 本次仅更新设计资源与文档，没有修改S00技术验证页、全局CSS、PWA运行时主题、API或数据库。

## 视觉还原与验收

AI栅格设计图没有完整字号、行高、间距、状态和响应式规格，不能承诺前端与图在所有设备完全一致。本项目先按COMMON和画面设计书的参数实现，再在同参考视口/示例数据下截图对照，调整布局、层级、颜色与控件；若图与业务规则或可访问性冲突，先修正图，不为贴图裁掉内容或缩小点击区域。

V1不强制使用专业设计软件。若要求严格像素级还原，可用Figma等补充明确的字体/字重/字号/行高、间距、尺寸、颜色、组件及各状态、断点和必要资源，再结合浏览器与真机验收。截图相似度不能代替API、交互、长文本、异常态和厨房设备验收。
