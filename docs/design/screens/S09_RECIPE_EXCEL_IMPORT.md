# S09 Excel 菜谱导入设计书

状态：V2第一项增量功能，Web页面已实现；使用浏览器解析固定 `.xlsx` 模板，复用 S05 的 A08/A09 JSON 校验和原子导入，不新增服务端文件上传或数据库逻辑。路由 `/recipes/import/excel`，组件 `RecipeExcelImportView.vue`。从 S05 菜谱导入 / 导出页进入。

## 1. 工作簿模板

模板只有一个名为“菜谱导入模板”的工作表。第1行必须保留下载模板生成的以下11列表头及顺序，不得增加其他表头。第2行为完整示例菜谱；真实菜谱从第3行开始，每行一道菜。

| 列  | 表头                                                   | 内容                                                      |
| --- | ------------------------------------------------------ | --------------------------------------------------------- |
| A   | 菜名（必填）                                           | 1～50字，必填                                             |
| B   | 简介                                                   | 可选                                                      |
| C   | 原份数                                                 | 正整数；留空按1人份                                       |
| D   | 准备时间（分钟）                                       | 非负整数，可选                                            |
| E   | 烹饪时间（分钟）                                       | 非负整数，可选                                            |
| F   | 难度（简单/中等/复杂）                                 | 可选，分别映射到 easy / medium / hard                     |
| G   | 标签（每行一个）                                       | 单元格内换行，每行一个标签                                |
| H   | 食材（每行：名称，数量，单位，备注，分组，随份数换算） | 单元格内每行一项；中文逗号分隔6段，名称必填，其他段可留空 |
| I   | 步骤（每行一步）                                       | 单元格内换行，每行一个步骤，按顺序自动编号                |
| J   | 小贴士                                                 | 可选                                                      |
| K   | 来源                                                   | 可选                                                      |

第2行菜名明确标为 `【示例，请勿删除】番茄炒蛋`，这是填写示例，请勿删除或修改。导入器始终按行号跳过第2行，即使该行内容被误改也不会导入；真实菜谱从第3行开始填写。若工作簿没有其他菜谱，则提示填写实际菜谱，不允许只导入示例。

食材单元格格式示例：

```text
鸡蛋，3，个，打散，，是
盐，适量，，，，否
```

食材六段依次是名称、数量、单位、备注、分组、是否随份数换算；新模板使用中文逗号 `，` 分隔，字段内容不能包含该分隔符。空字段仍需保留分隔符，例如只有单位时写 `鸡蛋，，个`。最后一段可用“是/否”或 `true/false`，留空默认随份数换算。已下载的旧模板仍兼容竖线分隔格式。

模板下载包含示例数据，且导入时自动跳过第2行，避免误把示例菜谱写入菜库。支持 `.xlsx`，不支持 `.xls`、CSV、多工作表、改名/调序的表头及公式单元格。

## 2. 页面流程

```text
下载模板 / 填写模板 → 选择 .xlsx → 本地读取与格式检查 → 服务端校验 → 确认导入 → 成功
                                                   ↘ 错误：按Excel行/字段修正后重新上传
```

- S05 保留 JSON 导入 / 导出行为不变，增加“使用 Excel 模板导入”入口；S09 可返回并切换至 JSON 页面。
- 选择文件后在浏览器内解析，仅将规范化后的菜谱 JSON 发送给 API，不上传或保存原始工作簿。
- ExcelJS解析包按需加载且不加入PWA预缓存；首次解析/下载模板以及A08/A09导入需要网络。
- 页面显示已解析菜谱数和最多5条菜名预览；格式/单元格错误以工作表行号定位，服务器字段错误也映射回Excel数据行。
- 最多1000道菜、源 `.xlsx` 文件及转换后的JSON请求体均不超过10 MiB。超限或格式错误时不请求写入。
- 为限制异常工作簿扫描量，最多读取10000个数据行位置；空白行不计入菜谱数。
- 点击“校验 Excel 内容”调用 [A08](../apis/A08_IMPORT_VALIDATE_POST.md)，显示全部可识别的字段与同名冲突问题；校验通过后明确提示尚未写入。
- 确认后调用 [A09](../apis/A09_IMPORT_POST.md)，复用原有整批事务。失败保留已选文件和错误；网络中断且结果不明时提示先检查菜谱列表，不自动重试。
- 操作期间禁用重复校验/提交；更换或移除文件即清除通过状态。导入成功显示数量及菜谱列表入口。

## 3. 验收

- 下载模板可在 Excel / LibreOffice 打开，工作表名、11列表头、示例菜谱行、冻结首行与筛选范围正确。
- 单菜可表达完整的菜谱输入字段；食材用中文逗号分隔字段，步骤/标签多行按原顺序转换，原份数和换算默认值与 shared Contract 一致。
- 第2行示例自动跳过并不会被导入；只含示例时阻止提交，错误和真实菜谱行号仍对应原工作表。
- 错模板、多工作表、空工作簿、特殊/公式单元格、额外列、空文件、超过1000道菜、10 MiB限制有可理解错误。
- A08 校验通过前不可提交；服务端字段问题能映射到原Excel行和字段；A09整批失败不显示成功数量，网络不确定不自动重发。
- JSON 页面与 API Contract 行为不变。

无独立设计图；本页沿用 S05 与全局 COMMON 的奶油黄样式，组件状态以本设计书为准。
