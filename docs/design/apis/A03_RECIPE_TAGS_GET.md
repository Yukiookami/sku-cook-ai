# A03 GET /api/recipes/tags

状态：源码已实现；初始迁移已应用于本地开发数据库；A03真实数据库HTTP行为尚未单独验收。调用方：[S01](../screens/S01_RECIPE_LIST.md)、表单可选标签建议。shared Contract：`RecipeTagsResponseSchema`。

## 请求 / 成功200

无Body或查询条件，不接用户id。返回当前默认用户所有菜谱里的标签，而不是某页或某搜索条件的标签。

```json
{ "tags": ["家常菜", "快手", "汤"] }
```

tags去重、无空值；按固定的字符串升序排序，前端不依赖某个系统语言环境的排序。没有标签返回 `{"tags":[]}`。

## 处理

按userId读取所需tag字段/关系 → 归一化后的集合去重 → 稳定排序 →返回，不创建分类或标签管理表单。删除/编辑后不存在于任何菜谱的tag不再出现。路由必须与 `/recipes/:id` 区分，不能把tags当id。

## 错误与测试

500 INTERNAL_ERROR或已识别数据库不可用503 SERVICE_UNAVAILABLE；不得在错误时成功返回[]。测试跨分页汇总、重复标签、删除最后引用后消失、用户隔离、tags静态路径匹配。前端标签失败可独立重试，不阻断列表。
